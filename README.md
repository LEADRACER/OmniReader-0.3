# OmniReader 🌌

A premium, universal document reader. Experience documents in a whole new dimension with smart summarization, interactive Q&A, and multi-language support.

**Download & Play** — no server, no backend, no build step required. Just open `index.html`.

## ✨ Features

- **📄 Multi-Format**: PDF, Markdown (.md), Plain Text (.txt)
- **🎙️ Voice Over**: Text-to-Speech with language-aware voices
- **🌍 Translation**: 6 languages (real translation coming in Phase 3)
- **🧠 Smart Reading Modes**: Detailed, Summary, Q&A (real AI coming in Phase 2)
- **💎 Premium Design**: Dark glassmorphism, dynamic nebula background, responsive

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/LEADRACER/OmniReader-0.3
cd OmniReader-0.3

# Install dependencies
npm install

# Development server
npm run dev

# Production build
npm run build
```

Or just open `dist/index.html` in your browser after building.

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Build | Vite (vanilla JS) |
| PDF | pdfjs-dist |
| Markdown | marked |
| State | Custom pub/sub + localStorage |
| Design | CSS custom properties, dark glassmorphism |
